# AI Story Generator 📖

An AI-powered story generation application using Python and Google Gemini 2.5 Flash.

## Features
- Multiple story genres
- Different writing tones
- Custom story lengths
- AI-generated stories
- Download stories in Markdown format

## Technologies Used
- Python
- Streamlit
- Google Gemini API

## Installation
pip install -r requirements.txt

## Run Application
streamlit run app.py

## API Configuration
Create a .env file and add:

GEMINI_API_KEY=your_api_key_here

Never share your actual API key publicly.
